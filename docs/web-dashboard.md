# Web 面板导航

[中文](#) · [English](en/web-dashboard.md)

登录后打开 `/dashboard`。左侧目录按工作区分组，可点击分组名称展开或收起；当前页面所在分组自动展开，浏览器在本次会话中保留其他分组的折叠选择。右侧用标签页切换同一主题的视图。窄屏点击左上角菜单按钮展开目录。

| 目录 | 内容 |
| --- | --- |
| 总览 | 待审批数、未处理告警数、Outbox 状态、最近风险会话和告警。 |
| 告警 | Judge 与运行时安全规则告警、确认操作和告警归并；页面标明来源。 |
| 审批 | 列表可直接拒绝；批准须进入详情，核对网关事实与低信任来源，再确认原始参数。 |
| 运行分析 | 会话调查（概览、目标偏移、行动链）、工具调用与审计（工具调用、审计事件、Judge 结果）、敏感数据流、威胁关联（事件证据、框架映射）。 |
| 记忆安全 | 长期记忆；记忆实验下用“跨会话污染”和“存储安全”切换原有两类实验。 |
| 安全实验与评测 | Agent 攻击实验下切换“综合攻击”和“目标偏移”；另有攻防验证与规则校准、Judge 评测。 |
| 管理配置 | 工具调用授权、防护规则（工具调用策略、运行时安全规则）、远程 MCP 接入、Judge 运行设置、系统与演示数据；默认管理员另可管理租户。 |

顶部“登录租户”是当前管理员的身份范围。研究实验页可选择只读查看专用研究租户；这时页面另行标明“数据租户”，不会切换登录身份，也不会扩大管理权限。租户管理入口只对默认管理员显示。

「审计与 Judge」的最近审计事件同时显示指定 Judge 和处理状态。配置变更、权限签发等只保存审计记录的事件显示「仅保存审计，不进入 Judge」；启用事件路由前就已完成的旧事件可能没有“指定 Judge”，但若存在 Judge 结果，页面会显示「已评判」和实际提供方。待投递、评判中和失败分别按 Outbox 状态显示；缺少应有的路由或投递记录才标为「需检查」。

表单操作完成后返回所属页面。一次性权限令牌与新租户凭据只在创建结果页展示一次，请当场妥善保存。目录名称不带开发阶段版本号；实验记录保留样本版本和哈希，以便复现。

“管理配置 → 远程 MCP 接入”现在显示合成远端的已批准修订、当前工具摘要、变化候选和行为探针异常。打开页面只读工具清单；点击“重新观察”会运行合成只读探针并记录变化。管理员可在核对差异后批准或拒绝固定工具的描述变化，或回退到端点身份相同的旧修订。新增工具与参数结构变化不能在页面直接放行；GitHub 固定工具仍按独立代码摘要管理。详见[供应链变更检测](mcp-supply.md)。

「运行分析 → 会话调查 → 目标偏移」只显示辅助线索，不改变工具授权。默认查看当前登录租户的日常记录；默认管理员可切换到目标偏移实验的研究租户，查看只读测试记录及其证据。审批事实卡的短时确认绑定管理员会话、租户、审批、固定参数与当前证据；刷新前若证据或状态变化，需要重新打开详情。实验详情的跨租户证据链接由服务器核对是否属于所选运行。

「管理配置 → 防护规则 → 运行时安全规则」展示网关当前使用的条件、阈值、处置、关联证据和局限，并标明会话绑定是否强制。此页只读；「工具调用策略」的 YAML 只控制单次工具调用的基础授权，不会修改运行时安全规则。具体命中可在「运行分析 → 会话调查」查看，需处理的命中在「告警」查看。

## Judge 评测切换

在「安全实验与评测 → Judge 评测」选择已配置的提供方，再点击样本的「评测」，会为该样本创建一次新的异步评测。页面按所选提供方展示每条样本最近一次完成的结果和误报、漏报统计。切换下拉框只改变查看对象；已有结果不会重新计算。Mock 总是可选；Jev、DeepSeek 和 OpenAI 兼容提供方在本机配置相应凭据或端点后出现。页面显示模型名和数据目的地，不显示密钥。

此处的选择仅作用于新提交的合成样本，提交后随 Outbox 路由记录保存，Worker 重试仍使用原选择。日常工具调用审计和告警使用「管理配置 → Judge 运行设置」中的租户选择；本页不修改该选择。云端评测会按现有脱敏规则发送合成事件，建议只放入合成数据。提供方只显示「已配置」，不表示远程服务当前一定可连接；连接失败时结果不会计入已完成统计，可在 Outbox 状态中排查。

## 会话调查与证据链接

会话调查的三个列表标签是同一工作区的不同视图：概览按会话汇总，目标偏移列辅助分析记录，行动链列受预算保护的会话。默认管理员选定研究租户后，切换三个标签保留数据租户；其他租户管理员只能查看自身数据。研究租户的概览和调用证据只读，不能通过切换标签获得管理权限。

会话详情另有“会话概览、目标偏移、行动链”标签，切换时始终查看同一个 session_id，并保留当前证据返回路径。概览呈现输出检查、记忆、时间线与复核；基本会话状态和已采集的任务、回答在各标签中保留，方便理解分析依据。原有详情 URL 继续可用。

工具调用与审计的列表用三个标签分别显示调用、审计事件和 Judge 结果。威胁关联把日常事件证据与框架参考放到两个标签，框架分类仍只表示线索。防护规则中的工具策略可以通过原有表单更新；运行时安全规则目录仍只读。

“管理配置 → 系统与演示数据”增加“故障隔离与恢复”页签（`/dashboard/resilience`），展示当前租户的熔断、队列、unknown 和隔离实验报告。重试按钮仅重投终止的 Judge／Webhook，不重放工具；操作需要管理员登录和 CSRF。


## Agent 安全委托

“运行分析 → Agent 安全委托”集中展示父身份与固定只读协作身份、受限范围、剩余额度、时效及原始调用证据。当前租户管理员可轮换／停用独立凭据及撤销委托；研究租户观察为只读。固定实验报告和真实委托分别显示，不把临时样本 ID 链接成日常调用。会话来源中，委托回复链接到委托详情，原始读取链接到真正的子调用，均带数据租户。
