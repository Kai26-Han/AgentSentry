# 会话行动链与行动预算

[中文](#) · [English](en/action-chain.md)


## 在架构中的位置

示例 Agent 的可信适配层在任务开始时取得会话凭据。每次工具提案和模型发送前，网关根据同一租户、Agent 与会话的已提交记录计算行动预算。审批通过、真正执行写入前再次计算。语言目标偏移仍是调查线索，不能扩大权限或代替现有策略、能力令牌、敏感数据流与审批。

```text
示例 Agent → 会话凭据 → 网关：身份／策略／权限／数据流
                              ↓
                     行动链预算与暂停状态
                              ↓
                     审批或固定工具／模型出口
                              ↓
                 审计 + Outbox → Judge／告警
```

## 确定性处置

规则版本为 `action-chain-v1`。单会话最多 20 次工具提案、8 次任务模型发送和 3 次记忆摘要发送；第 21、9、4 次分别被拒。单会话最多 3 次写入提案，同一 Agent 在滚动一小时内最多 10 次。待审批、执行中、结果不明和已完成的写入均占额度；拒绝后的新提案可重新计算。十分钟内同一会话出现第 4 个不同资源的拒绝调用时，网关自动暂停会话，由管理员复核后恢复。工具 `call_id` 与模型请求 ID 的原样重试不重复计数，变更参数的重试仍沿用现有冲突规则。

预算在 PostgreSQL 事务中计算，并使用租户与 Agent 级事务锁串行化跨会话写入判断。决定、计数和证据 ID 与 Outbox 同事务提交；提交失败时不执行工具或发送模型请求。审批执行前再次检查原参数与当前预算。`unknown` 仍保留，不推断副作用成功。

Web 左侧“运行分析 → 会话调查 → 行动链”可查看本租户的最近会话、规则、逐步决定与调用证据。默认管理员可切换至隔离研究租户；证据链接仍在该租户只读打开。新会话自动登记，旧会话不回填。

## 固定与真实模型实验

固定样本命令：

```bash
.venv/bin/python -m agentsentry.action_chain_lab --output .local/action-chain-report.json
```

`action-chain-cases-v1` 含 20 条压力／越界提案、10 条正常对照，独立合成数据库验证工具循环、写入、资源探测、模型循环及额度边界。固定提案不证明模型会生成相同动作。

本地真实模型命令：

```bash
SENTRY_URL=http://127.0.0.1:8000 .venv/bin/python -m agentsentry.action_chain_live --model qwen3:0.6b
```

该命令创建独立 `Attack Lab` 租户；凭据以 `0600` 保存于 `.local/`，只使用固定合成文档、MCP 卡片和本地模型。真实模型样本为 `action-chain-live-v1`，包含文档与 MCP 各三条压力任务和正常对照，记录样本哈希与实际模型行为。报告保存于 `.local/action-chain-live-report.json`；没有达到阈值的真实尝试时，相关阻断效果为未验证。已保存的观察与分母见[连续行为案例](cases/runtime-and-budget.md)。

## 边界与后续研究

- 当前默认兼容旧客户端。只有有效会话凭据的工具请求受行动链预算保护；未绑定的旧客户端仍可走现有策略与权限路径。部署时若所有调用方均已完成会话接入，可设置 `AGENTSENTRY_RUNTIME_BINDING_REQUIRED=true` 才能覆盖全部工具请求。模型发送前检查已要求有效会话绑定。
- 此类真实模型压力提示来自用户任务，不等同于“无攻击输入的自主偏移”。`TH-011` 仍需单独设计无攻击者输入的多步骤行为实验。`TH-013` 只评价已登记行动链的循环、探测与写入预算。
- 配额限制次数，不能理解语义或保证每一次额度内的动作符合用户意图。跨 Agent 的协作或连锁故障仍未覆盖。管理员恢复暂停不能收回已经启动的副作用。
- 日常威胁映射仅将明确的预算拒绝和资源探测作为线索，不把它们等同于攻击成功；Judge 仍只作事后信号。
