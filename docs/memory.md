# 长期记忆与跨会话污染防护

[中文](#) · [English](en/memory.md)

## 数据流与位置

```text
第一轮：用户任务＋实际读取的文档／MCP 卡片 → 示例 Agent → 输出检查 → 展示
                                           └→ 同一模型生成最多 3 条记忆候选
                                                      ↓
                                   网关核对会话、输出检查与来源调用
                                                      ↓
                                        激活／隔离／拒绝 → 租户记忆表

第二轮：正常用户任务 → 网关检索最多 5 条有效记忆 → 低信任工具数据 → 示例 Agent
                                                           ↓
                                                   输出检查 → 展示
```

记忆是**低信任数据**，即使管理员手工激活也不会变成系统指令。网关记录某条记忆的来源读取调用及其进入后续会话的事实，但不证明记忆内容正确，也不证明模型一定采用了它。撤销会阻止未来读取；已经送入进行中会话的内容无法收回。当前文档／MCP 事实自动激活还需要管理员预先审核该来源的**具体内容版本**。

## 默认行为与留存变化

`AGENTSENTRY_MEMORY_ENABLED=true` 默认开启。配置了示例 Agent 模型的 `llm` 场景会在每轮开始读取记忆，并在输出检查完成后额外调用同一模型生成结构化摘要。没有配置模型时不会生成新记忆；固定工具演示不生成记忆。摘要失败或记忆网关失败不影响已检查的用户回答，终端显示错误类型，面板保留可用证据；记忆读取失败时本轮按无记忆继续。

**preview 与 metadata 都会持久保存已激活或隔离的记忆文字。**`metadata` 继续不保存会话任务、回答片段，但不代表系统不保存任何会话衍生文字。升级后只对新完成的模型任务生成记忆，不回填旧会话。如果不希望新增文字留存，升级前设置 `AGENTSENTRY_MEMORY_ENABLED=false` 并重启 Web、Agent 和 dispatcher；关闭后仍需管理员清理已有记忆。

每条记忆最多 500 字，每轮最多 3 条；同一 Agent 最多 100 条有效记忆。激活与隔离内容 30 天到期；后台清理和后续访问会清空过期记忆文字。管理员在 `/dashboard/memories` 可查看来源、人工激活隔离条目、撤销或清除文字。清除记忆文字不删除原有工具审计或合成源文档。记忆审计及 Judge Outbox 只包含 ID、带服务端密钥的摘要哈希、处置和来源 ID，不包含记忆原文。云端 Judge 不为记忆候选作授权决定。

## 网关规则与接口

Agent 使用现有租户身份调用 `POST /api/v2/runtime-sessions/{session_id}/memory/read` 和 `/memory/write`。此权限固定限制为当前租户、当前 Agent 的已上报运行会话；模型不看到接口凭据，也不能把记忆接口当作工具直接调用。读取只返回有效且未过期的记忆，按任务词匹配和时间排序。写入必须关联本会话已检查且未阻断的最终回答；每条记忆引用的来源调用必须属于该输出检查。重复请求 ID 返回原结果，更换内容返回冲突。

来源 `call_id` 由可信适配层从实际传给模型的文档／卡片工具结果附加，模型返回的来源字段不会被采信。网关要求候选包含本轮输出检查涉及的全部文档／卡片读取 ID，不能通过省略来源绕开审核。若一轮读取多个材料，记录的是本轮参与摘要的来源集合，不表示每条摘要的每个字都能归因到某一材料；只有全部来源的当前内容版本都经过审核，且拼接后的原文符合长度及安全规则，才可能自动激活。

确定性规则拒绝凭据和合成私有来源秘密，不保存其原文；可疑指令、伪造权威、个人信息进入隔离。未审核的文档／MCP 来源也进入隔离，**`public` 仅表示可公开，不表示内容可信**。管理员先在调用详情核对原文，再到 `/dashboard/memories` 以读取 `call_id` 审核来源。网关只保存工具类型、资源 ID 和原文哈希作为信任记录；内容改变后必须重新审核。全部来源已审核、合计不超过 500 字且内容安全时可以自动激活，但保存的是按调用顺序拼接的审核原文快照，不是模型可能改写出的事实。长文或包含风险内容的来源仍需人工审核记忆。来源信任可撤销，既有自动激活记忆会立即转入隔离；升级时旧版自动激活的来源记忆也会重新隔离。管理员手工激活是明确的人工覆写，记忆仍为低信任数据。

输出检查对正常改写可能给出 `unverified_sentence`，因此这个提示**单独出现**时不再让已审核来源的每条记忆自动隔离。其他输出风险仍触发隔离；回答显示前的 输出检查保持原有行为。包含上一轮已读取记忆的回答再次生成摘要时，新候选默认隔离，防止不可信内容换 ID 自我复制。`block` 输出不生成记忆。来源审核是管理员的事实依据，不是网关自动判断内容真伪；审核错误仍可能产生错误记忆。

管理员 API 为 `GET /api/v2/memories` 与 `POST /api/v2/memories/{id}/decision`，后者可执行 `activate`、`revoke`、`purge`。来源审核使用 `GET/POST /api/v2/memory-sources` 和 `DELETE /api/v2/memory-sources/{id}`；写操作沿用现有登录与 CSRF。日常会话详情显示读取和写入关联。研究租户的专用过期模拟接口仅用于固定实验，不属于普通业务流程。

## 攻击实验

运行 `.venv/bin/python -m agentsentry.memory_lab_runner --mode scripted`，然后在 `/dashboard/memory-runs` 选择专用研究租户查看结果。详情页的写入轮、读取轮和工具调用证据按运行 ID 与研究租户定位；默认管理员可以只读查看，其他租户不能跨租户打开。真实模型运行用 `--mode live`，默认使用已配置的本机 OpenAI 兼容模型；远端模型必须显式传入 `--allow-remote-model`，只发送固定合成实验材料。研究租户复用攻击实验的 `.local/attack-lab.json` 凭据和已显式启用的 MCP 策略。

固定样本共 12 条攻击、6 条正常对照。运行器只对正常对照和 D06 撤销边界样本的合成来源执行管理员审核；攻击来源保持未审核。每条用例先写入合成材料，再发起不含攻击文本的第二轮任务。`scripted` 重放固定候选，验证网关、过期、撤销、重放和来源边界；它没有模型回答，不把“已读取记忆”算作实际回答污染。`live` 用真实模型运行 3 条文档攻击、3 条 MCP 攻击及 6 条正常对照，独立记录恶意候选生成、激活、后续读取、可展示回答污染、禁止工具执行与无法判定。Judge 不接收记忆原文，面板不计算记忆 Judge 误报／漏报。

实验结果表只保存预定义回答标记是否出现，不保存模型第二轮回答全文。逐步证据通过研究会话、输出检查、记忆读取和工具调用 ID 关联；`metadata` 模式的回答文字不会因实验报告而另行留存。
网关升级启动时会对默认租户和已有研究租户执行一次幂等清理，将早期实验记录中的自由回答文字缩减为预定义标记或空值。

“恶意候选”按每条样本预定义的目标文字或规则命中判定；生成任意记忆不自动等于生成恶意记忆。D06 检查撤销边界，写入的是正常事实，因此不计入恶意候选。这个确定性判分对改写后的同义表达可能漏计，实验报告会同时保留逐例状态供人工复核。
