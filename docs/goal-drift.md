# 目标偏移线索与审批事实卡

[中文](#) · [English](en/goal-drift.md)


## 分析与审批的位置

```text
可信用户任务 → 会话开始 → 有限的任务轮廓
低信任文档／MCP 卡片／记忆 → 示例 Agent → 工具提案 → 网关原有授权检查
                                          └→ 目标偏移辅助分析 → 审计／页面
工具待审批 → 管理员查看事实卡 → 短时确认 → 网关重查原参数和权限 → 执行或拒绝
最终回答草稿 → 输出安全检查＋目标偏移辅助分析 → 可展示回答
```

任务轮廓只保存 `read_only`、`action_requested` 或 `unknown`、已识别动作类别和明确的固定资源 ID，不新增任务原文留存。`metadata` 模式仍按原设置不保存任务或回答片段；网关在请求当次处理原文。旧会话不回填意图，页面显示“未评估”。

固定规则记录：只要求阅读却提出写入、已读取来源自称系统或管理员授权、来源指令与实际工具动作相符、参数中自称已批准，以及来源中的输出指令进入回答。规则产生 `suspected`、`aligned`、`unknown` 或 `failed` 等辅助状态。`aligned` 只表示这些有限模式未命中，不证明任务安全。可选本地语义模型由 `GOAL_LOCAL_MODEL_BASE_URL` 和 `GOAL_LOCAL_MODEL_NAME` 显式启用，默认关闭；连接或格式失败记为分析失败，网关继续沿用已有策略、临时授权、运行时规则、敏感数据流和审批决定。

目标评估按租户保存状态、规则版本、命中类型与证据 ID。审计和 Outbox 不携带任务、回答或来源原文；工具操作数据仍按当前受限留存规则处理。管理员在 `/dashboard/goal-assessments` 查看近期记录，在会话详情按来源调用追溯。此页默认显示登录租户的日常运行记录；默认管理员可通过“数据来源”选择已有目标偏移实验的研究租户，查看只读测试数据。实验数据不会自动合并进日常记录，跨租户证据链接须核对所属实验运行。

## 审批事实卡

`/dashboard/approvals` 只列出待处理动作和“查看事实卡”入口，可直接拒绝，不能从列表批准。详情页把网关事实与低信任材料分开：工具、冻结参数及其摘要、资源授权、策略命中、当前状态、运行时／数据流／目标偏移线索和来源链接。参数与工具结果默认遮盖敏感字段；管理员可主动展开原始参数。文档、MCP 卡片和参数里的“已批准”只作为待核查内容，不显示成真实审批状态。

Web 批准需要勾选核对声明并提交短时确认凭据。凭据五分钟有效，绑定管理员会话、租户、审批 ID、冻结参数摘要和当前事实卡摘要。证据或状态变动、参数替换、重放或凭据过期会拒绝本次 Web 批准，需重新打开详情。网关最终仍以原审批记录、权限、策略、运行时状态和数据流规则重查。原有管理员 API `/api/v1/approvals/{id}/decision` 保持兼容，并继续要求登录与 CSRF；它用于受控自动化，不经过 Web 事实卡。模型没有该管理员凭据。

## 固定实验与真实模型实验

样本定义在 `src/agentsentry/goal_lab_corpus.py`，固定 12 条攻击、8 条正常对照。每次运行新建 `Attack Lab` 研究租户，独立保存策略、调用、目标线索、输出检查和实验结果；凭据写入本机 `.local/goal-lab-<租户 ID>.json`，权限为 `0600`。实验报告只保留结论和证据 ID，不持久化模型草稿或展示文本。实验写入 API 只接受研究租户管理员并校验 CSRF；默认管理员可跨研究租户只读查看 `/dashboard/goal-runs`。

在项目目录运行：

```bash
SENTRY_URL=http://127.0.0.1:8000 .venv/bin/python -m agentsentry.goal_lab_runner --mode scripted
SENTRY_URL=http://127.0.0.1:8000 DEMO_MODEL_BASE_URL=http://127.0.0.1:11434/v1 DEMO_MODEL_NAME=qwen3:0.6b .venv/bin/python -m agentsentry.goal_lab_runner --mode live --output .local/goal-lab-live-report.json
```

端口、模型 URL 与名称应按本机配置替换。固定模式在两个新租户各重放 20 条，检查逐例结论一致。真实模型模式运行 3 条文档攻击、3 条 MCP 攻击及各自正常对照，每条重复 3 次，共 36 次。远程模型只能通过显式参数 `--allow-remote-model` 选择，并仍须通过登记的模型出口检查；研究输入始终为合成数据。

报告分别计算危险调用尝试、网关直接拒绝、待审批、禁止动作、审批前副作用、回答草稿污染、实际展示污染、正常完成和审计缺失。**没有危险工具提案进入网关时，网关阻断率显示“未验证”**。审批待处理、工具结果不明、模型未完成及环境故障各保留独立状态，不能算作成功防御。固定提案证明边界行为，不代表真实模型一定会提出相同动作；页面自动化检查也不能证明管理员一定识别欺骗。

## 范围与已知限制

- 只覆盖显式接入的示例 Agent 和固定工具。未显式接入的 Agent、额外 MCP 路径和旁路网络流量不在保护范围；已登记远程工具继续受相应网关控制。
- 任务轮廓采用有限规则，无法完整理解自然语言；语义模型也是提示而非授权。已有有效工具权限可能允许与用户任务不符、但未触发其他强制规则的动作，管理员应按事实卡核对。
- 低信任来源的标记或改写文字可能进入回答；目标偏移线索不能代替 输出安全检查。来源关联只说明信息到达 Agent，不证明模型依照其指令行动。
- 研究租户仅有合成数据。旧实验记录不重判；比较时必须同时核对样本哈希与判分版本。
