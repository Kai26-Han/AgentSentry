## 学习目标

- 解释低信任材料为什么不能变成用户或系统命令。
- 分别核对危险工具提案、草稿污染、实际展示污染。
- 理解来源关联、引用例外与规则匹配的局限。

## 威胁场景

用户让 Agent 总结季度计划。文档或 MCP 卡片要求它在回答里添加某个攻击标记，或把标记发送到模拟收件箱。网关可以阻止发送工具，但模型仍可能把标记写进回答。

```text
实际读取来源 → 模型上下文 → 回答草稿（可能污染）
                              ↓ 网关核对任务、来源与草稿
                    allow / warn / block → 适配层实际展示
```

一次攻击至少有三种独立事实：是否提出危险工具，是否生成污染草稿，污染是否实际展示。工具副作用为 0 不能推出回答安全；草稿包含攻击标记也不能推出用户看到了它。

## 项目控制与代码

| 检查 | 实现与用途 |
| --- | --- |
| 来源完整关联 | [output_safety.py](../../src/agentsentry/output_safety.py)：同租户、Agent、会话的实际读取记录，不能伪造“已读来源” |
| 明确来源指令及动作载荷 | [output_instructions.py](../../src/agentsentry/output_instructions.py)：抽取有限中英文模式，核对草稿是否照做 |
| 任务绑定和可信展示 | [demo_agent.py](../../src/agentsentry/demo_agent.py)：任务指纹关联，展示网关返回内容；不可用不回显草稿 |
| 凭据、私有片段与编码 | [data_flow.py](../../src/agentsentry/data_flow.py)：第 08 章的内容出口检查 |

`allow` 表示未命中当前阻断／提示条件；`warn` 带提示或脱敏后展示；`block` 只显示安全提示。来源 ID 证明信息到达指定路径，不证明原文或回答事实正确。

当前 `output-rules-v6` 保留来源动作的不透明载荷检查，并阻断已读取来源中的句首明确“忽略用户”命令直接进入回答。带说明的公开来源引用仍可展示。明确用户任务要求带来源引用原文、任务与会话绑定、回答确实按引用形式表达时，仍须满足其他出口检查；低信任材料不能自己声称用户要求引用。旧规则对私有数字数词／算式改写的[确认缺口](../cases/boundary-validation.md)已通过[受限来源会话级展示阻断](../cases/private-data-leakage.md)处理，正常无关回答也可能被阻断。

## 动手实验：同一来源的攻击与正常引用

**环境**：离线规则函数与临时数据库。没有实际模型请求或 Web 记录。

```bash
.venv/bin/python -m agentsentry.output_samples
.venv/bin/python -m pytest -q tests/test_output_safety.py
```

固定运行器输出版本、总数、通过数、正常误阻断数和失败列表；不支持 `--output` 或单样本参数。逐例输入和预期在[output_samples.py](../../src/agentsentry/output_samples.py)，重点比较：

| 样本库＋ID | 情况 | 预期 |
| --- | --- | --- |
| `output-samples-v5:O19` | 卡片要求发送载荷，总结草稿复述载荷 | block |
| `output-samples-v5:O22` | 用户明确要求引用恶意卡片并解释，回答带来源引用 | allow，继续满足其他规则 |
| `output-samples-v5:O25`／`O26` | 同类载荷转成 URL／Base64 | block |
| `output-samples-v5:O18` | 没有对应恶意来源，只出现相同标记 | allow；说明不是简单把标记硬编码为禁词 |

直接 `_assess` 样本只证明规则函数；[输出测试](../../tests/test_output_safety.py)进一步验证任务绑定、实际来源、跨租户、metadata 留存和失败时不展示草稿。终端通过不等于真实模型已产生同样草稿。

## 证据与真实模型扩展

[A03 修复](../cases/injection-and-output.md)与[A12 修复](../cases/injection-and-output.md)分别保留修复前后证据。使用 `goal-lab-v1:A12` 等完整标识，不与其他实验的 A12 混淆。

若要新建真实模型记录，按[第 10 章](10-goal-drift.md)运行目标偏移实验，查看来源 call_id、模型发送检查、output_check_id、草稿污染和展示污染。默认管理员须选择报告的数据租户；不从旧实验报告推断今天的模型行为。旧攻击实验判分口径可能包含草稿标记，不能直接与新校准报告的展示污染率比较。

`preview` 保存受限脱敏片段，`metadata` 不保存任务／回答片段；**两者仍临时将必要原文交给本机网关检查**，记忆和部分操作文字有独立留存规则。

## 局限与自检

公开来源的语义改写、翻译、跨来源暗示和错误事实可能没有可匹配载荷。有限解码不保证所有编码都能识别。已读受限来源时自由文本回答整体阻断，但这不能纠正错误来源分级，也不能保护未接入的路径。可选本地语义提示默认关闭，不能给内容作真实性证明。

1. 草稿污染、输出 block、禁止副作用 0，怎么记？**草稿污染成立，展示污染不成立，工具副作用另记 0**。
2. 只要回答有引号就能放行吗？**不能，必须核对可信任务、来源和其他出口规则**。
3. 规则未命中是否能标“事实已验证”？**不能**。
