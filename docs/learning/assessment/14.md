## 独立解释与变化题

1. **解释任务**：区分授权故障、依赖故障、Judge 故障及 unknown。
2. **自检**：何时能重试？熔断恢复为什么仍需授权？
3. **变化题**：旧代次成功为何不能关闭新熔断？运行 late_success 测试。
4. **局限**：先自己写出一条；再与提示对照：主机、数据库和 Redis 仍是共享故障域。

变化题改动只限临时样本或临时文件；先说明预期再运行。未经核对的产品问题记录为问题，不修改正式规则以获得通过。
