## 组件、凭据与数据

| 术语 | 项目中的含义 | 常见误解 |
| --- | --- | --- |
| Agent | 主示例 Agent 接收任务并提出工具与回答；委托演示另有固定只读协作身份 | 每个实验室都有新 Agent 或所有 Agent 都能写入 |
| 可信适配层 | 持有身份／授权、构造协议请求、实际发送获准消息并展示获准回答的代码 | 内容经过它就变得可信 |
| 安全网关 | 独立核验并保存同步安全决定的 FastAPI 服务 | 已透明拦截所有程序或网络流量 |
| 沙箱 | 限制获准 Shell 的执行环境 | 代替授权或保证不存在容器逃逸 |
| MCP | 工具定义、调用与结果的协议接入 | 协议正常就意味着内容无注入、执行已隔离 |
| Agent 身份密钥 | 识别租户／Agent 的凭据 | 能自行签发工具权限 |
| Capability／工具调用授权 | 不透明临时令牌，限定工具、资源、期限和次数 | 与 YAML allow 等价或自动取消审批 |
| 会话凭据 | 绑定已上报会话、Agent、租户和有效期的服务端凭据 | session_id 字符串本身就有权限 |
| 管理员登录与 CSRF | 管理操作的身份和请求保护 | 最终批准能跳过原参数／当前状态复核 |
| call_id | 同一租户工具调用的幂等及关联 ID | 换 ID 重做仍算原样重试 |
| session_id | 关联某次任务的会话标识 | 是授权、内容或全局唯一主体 |
| 来源 ID | 实际工具读取或记忆进入上下文的关联记录 | 证明内容事实正确、模型已经服从 |
| 低信任数据 | 文档、卡片、工具结果和记忆等材料，只作为数据 | 必定恶意或必定秘密 |
| public／private／secret | 服务端来源事实与明确凭据决定的敏感级别 | 内容自称 public 可降级；public 就可信 |
| 规范化摘要／HMAC | 规范化请求的摘要；部分场景使用服务端密钥保护指纹 | 加密原文或全面匿名化 |

## 决定和状态

同名词必须同时看对象。目标轮廓的 unknown 与工具结果 unknown 是不同状态。

| 对象 | 状态 | 应怎样理解 |
| --- | --- | --- |
| 基础策略 | allow／deny／require_approval | 基础效果，最终仍叠加身份、授权与同步控制 |
| 工具调用 | pending_approval | 动作在等审批，不能计正常任务已完成 |
| 工具调用 | executing | 可能已进入执行阶段，不能推断副作用为 0 |
| 工具调用 | completed | 已保存可确认结果；仍需看动作是否正常且获准 |
| 工具调用 | failed | 有确认的失败信息，需核对失败阶段 |
| 工具调用 | unknown | 无法确认实际副作用；不自动重发、不算成功防御 |
| 输出检查 | allow／warn／block | 原文展示／带提示或脱敏展示／只展示安全提示 |
| 记忆 | active／quarantined／rejected | 可供后续读取／隔离不返回／拒绝保存候选原文 |
| 记忆 | revoked／expired／purged | 撤销／到期／主动清文字；留存与读取规则不同 |
| 目标分析 | suspected／aligned／unknown／failed | 有辅助线索／有限规则未命中／任务不清／分析异常，不独立授权 |
| Judge／Outbox | 待投递、评判中、完成、失败 | 异步处理进度，不等同于工具执行状态 |
| 威胁映射 | 待映射、已关联、无匹配、失败 | 类型化条件投影结果，不是攻击成功判定 |

原样重试返回已记录状态；换内容冲突通常为 409。入口非法参数可能是 422，身份不足可能是 401／403，租户不可见记录可能是 404；不能只从单个 HTTP 数字推断副作用。

## 隐私与清理

| 概念 | 含义 |
| --- | --- |
| preview | 保存受限长度的脱敏任务／回答片段；原文仍临时用于网关检查 |
| metadata | 不保存任务／回答片段，但检查原文仍临时进入网关；记忆和部分操作文字另有留存 |
| 脱敏 | 用确定性规则识别并替换已知敏感模式，可能漏掉未知格式或语义关联 |
| 面板遮盖 | 默认不显示操作正文，展开权限和存储留存仍独立存在 |
| 撤销 | 阻止未来使用，不保证删除文字或收回已进入会话的内容 |
| 过期 | 到期不再返回；当前签名有效的过期记忆在清理／访问时清文字，异常记录另处理 |
| 清除原文 | 指定记录文字字段清空，保留关联元数据；不等于清除备份或关联工具源文档 |
| 关闭功能 | 停止后续记忆读写，不自动删除已存记忆 |

## 验证与评判

| 概念 | 含义与分界 |
| --- | --- |
| scripted／固定重放 | 提交固定提案，证明边界响应；不证明模型一定会产生这些提案 |
| live／真实模型 | 模型实际运行任务，记录行为；输出可能变化，未尝试时控制未触发 |
| 草稿污染 | 网关检查前模型回答出现样本定义的污染内容 |
| 展示污染 | 网关返回且适配层实际可展示的内容仍含污染；阻断草稿不算展示污染 |
| 危险尝试 | 实际提出样本定义的危险动作，与执行成功分开 |
| 禁止副作用 | 本不应获准的读取／写入或其他效果实际发生；合法合成任务不能混算 |
| 无法判定 | 待处理、不明结果、模型未完成、环境故障或缺证据，须说明具体原因 |
| 误拦候选 | 正常任务被拒绝或升级审批，可能有保守限制；需因果核对才归因到规则 |
| Judge 分数 | 提供方对收到事件的风险信号值，不是经过校准的攻击概率 |
| 校准集／保留集 | 前者用于评估建议，后者检验泛化和新增风险；不能反复拿保留集成绩调参却称独立验证 |
| TH／ASI／ATLAS | 项目威胁场景／OWASP 风险类别／MITRE 技术索引；映射线索不代表风险已经解决 |

“功能已实现”“指定范围内已验证”“部分验证”“未验证”“当前不适用”是不同结论。当前矩阵用“已确认缺口”记录有证据的问题；后续修复附新证据，历史报告不改写。

## 建议的自检方式

解释一个术语时给出：**它检查什么、在哪里检查、用什么事实、失败时怎样处理、不能保证什么**。只背名称不足以理解机制。
