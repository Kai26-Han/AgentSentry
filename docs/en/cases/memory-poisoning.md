## Question

An attack can become long-term memory and affect a later normal task without attack text. Content review and storage integrity are distinct; a valid signature is not truth.

## Observations and fix

2026-09-28 scripted memory set (12 attacks/six controls) activated and later recalled invented-fact D04/M04 memory, 2/12. Without real answers, recall was not proof of answer contamination. The original live run had no malicious activation but only 1/6 normal usable memories, exposing false quarantine.

The fix binds completed sources, content hashes and review versions. Automatic activation stores reviewed short public source snapshots rather than arbitrary model paraphrases. Unreviewed/private/long/suspicious content quarantines; changed/revoked sources invalidate old linkage. Recall and output recheck.

## Reproduce and retention

Follow [memory exercises](../learning/07-memory-security.md), separating generation/activation/recall/answer/effects. See [memory](../memory.md), [integrity](../memory-integrity.md) and [observations](../../cases/evidence/boundary-observations.json).

Only eligible own-tenant/Agent memory returns; quarantine/revoke/expiry prevents later reads. Memory is low-trust, default 30 days; manual activation grants no external egress and revoke cannot recall in-flight context. **Both preview and metadata retain memory text**; disabling stops later read/write without deleting it.

Review can be wrong; secrets may be misclassified and semantic paraphrases missed. No malicious activation or valid signatures do not establish universal cross-session safety.
