## Learning goals

Keep low-trust material separate from instructions; distinguish proposals, drafts, and display; understand quotation exceptions and matching limits.

## Threat

A plan document or MCP card demands an attacker marker in the summary or a send to the simulated inbox. Tool denial can coexist with a contaminated draft.

```text
Actual source → model context → potentially contaminated draft
                     → gateway checks task/source/draft
                     → allow / warn / block → actual display
```

Check dangerous call, contaminated draft, and displayed contamination separately. Zero tool effects is not answer safety; a marker in a blocked draft is not user-visible contamination.

## Controls and code

[output_safety.py](../../../src/agentsentry/output_safety.py) verifies actual tenant/Agent/session sources. [output_instructions.py](../../../src/agentsentry/output_instructions.py) extracts limited English/Chinese instructions and action payloads. [demo_agent.py](../../../src/agentsentry/demo_agent.py) binds tasks and displays permitted content; failed checks do not echo drafts. [data_flow.py](../../../src/agentsentry/data_flow.py) handles sensitive exits.

allow means no current finding; warn displays permitted/redacted text with a notice; block displays only a safe notice. Provenance is not truth.

Current output-rules-v6 retains explicit payload/source-command controls and blocks free-form output after private/unknown/secret reads. Legitimate public quotation requires the actual bound user task and quotation form, and still passes other checks. Source text cannot claim the user requested it. The [private-number gap](../cases/boundary-validation.md) led to [session-wide restricted-source blocking](../cases/private-data-leakage.md), which also blocks unrelated normal answers.

## Limits and self-check

Public semantic rewrites, translation, cross-source hints, and false facts can escape finite patterns/decoding. Restricted-session blocking does not fix misclassification or bypass paths. Optional local semantic hints are not truth verification.

A polluted draft + block + zero forbidden effects means draft contamination only. Quotation marks alone do not authorize display. No rule match cannot be recorded as verified truth.
