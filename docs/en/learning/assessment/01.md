## Explain, vary and state limits

1. **Explanation:** Draw decision, commit, actual execution and asynchronous audit paths.
2. **Self-check:** Why commit first? Is Judge failure the same as authorization failure?
3. **Variation:** Compare result-commit failure after execution with commit failure before execution: when is unknown appropriate?
4. **Limit:** write your own first, then compare: Database and tool execution are not one atomic transaction.
