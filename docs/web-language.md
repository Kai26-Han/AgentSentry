# Web 中英文切换

[中文](#) · [English](en/web-language.md)

本功能用于 GitHub 分享副本的 Web 界面。登录页和页面右上角提供「中文／English」；默认中文，选择后立即返回当前页。浏览器会记住选择，退出登录后仍保留语言偏好。

## 翻译范围

导航、面包屑、页面标题、表单标签、按钮、空白说明、审批事实卡、规则说明、Judge 分数解释、实验页面以及可信的项目威胁描述均提供英文。

以下内容保留原文：用户任务及回答、工具返回内容、文档和 MCP 卡片、记忆文字、自由填写的备注、原始参数与审计 JSON、标识符、工具名、规则 ID、配置名称和命令。这些是调查和实验的数据，界面切换不改变它们。用户自编写的中文样本和证据也不会自动翻译。Markdown 文档另有独立英文版，见 [English README](../README.md) 与[英文学习手册](en/learning/README.md)；界面语言选择不会改写文档正文。

## 实现方式

- [界面翻译模块](../src/agentsentry/i18n.py)按每个请求的 `agentsentry_language` Cookie 选择语言，不设置共享的全局当前语言。
- [英文目录](../src/agentsentry/locales/en.json)保存中文界面文字到英文的对应关系；模板以 `_()` 或显式 `ui` 过滤器翻译可信界面描述。不是调用云端模型翻译，不发送页面或会话数据。
- `/ui-language/zh`、`/ui-language/en` 只设置显示偏好。跳转仅接受应用内的登录或面板路径，保留当前筛选参数；未知语言拒绝。
- 登录身份、租户隔离、CSRF、审批确认、参数摘要、API 请求与响应格式均独立于界面语言。
- 新增界面文字时应同时添加英文；[语言测试](../tests/test_i18n.py)校验翻译目录、不同浏览器的语言隔离、安全跳转、原文保留、HTML 转义及英文审批边界。

## 本机分享副本

当前本机独立分享服务使用 `localhost:18766`；一般新安装使用自己的 `AGENTSENTRY_PORT`。语言选择只影响对应浏览器中的站点，不改写 `.env` 或其他服务配置。
