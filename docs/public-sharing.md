# 公开文件与隐私约定

[中文](#) · [English](en/public-sharing.md)

公开内容按两类组织：**主入口**（README、总纲、架构、学习手册与操作说明）和**进阶案例**（安全问题、实测事实、修复与取舍）。不提供开发历史、原始路线或参考归档入口。

## 可分享什么

- 应用源码、模板、示例 Agent、固定工具、MCP 适配器与受限沙箱。
- 测试、安全 CI、人工编写的合成样本、默认策略和策略用例。
- Docker 配置、依赖清单／锁文件及只有占位符的 `.env.example`。
- 独立中文与英文说明、学习手册、[进阶案例](cases/README.md)、受限脱敏事实摘要及威胁映射。

样本中的攻击文字、假凭据和测试身份是学习材料，不是真实业务数据或可用密钥。公开案例注明模式、日期和版本；新安装需生成自己的运行记录，不能打开原作者的私人 Web 证据。

## 不分享什么

| 文件或数据 | 处理要求 |
| --- | --- |
| `.env`、管理员凭据、模型／Judge／GitHub 密钥 | 只留本机，不进入版本库、聊天、截图或容器构建上下文 |
| `.local/` | 研究租户凭据、实验轨迹与个人记录不提交 |
| 数据库、日志、卷与原始业务报告 | 不随项目分发；使用合成、受限的结论摘要 |
| `policies/t_*.yaml` | 不提交本机生成的租户策略；只提供默认示例 |
| 虚拟环境与缓存 | 按锁文件重新安装 |
| 私人仓库地址、个人路径、私人运行标识 | 从贡献材料移除，不伪造可查询证据链接 |

`.gitignore` 与 `.dockerignore` 提供排除规则，但手工打包文件夹仍需检查。服务启动后会产生私有配置和记录，它们不属于公开文件集。假测试密码不可用于实际服务。

## 新安装与贡献

从 [README](../README.zh-CN.md#快速启动)启动，使用自己的随机凭据。云模型、云 Judge 和第三方 MCP 显式配置；GitHub 写入使用专用合成测试仓库、独立 PAT 和人工审批，会产生真实外部副作用。

提交学习结果时，记录模式、日期、样本／规则版本、决定、实际副作用、展示及无法判定项，见[贡献指南](../CONTRIBUTING.md)。保留失败与修复前后事实，不复制日常原文，不用已有案例成绩代替新的运行。
